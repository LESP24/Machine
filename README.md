# 🧠 Browser-Based ML Classifier

A web application that deploys a machine learning model directly in the browser using **TensorFlow.js**. This project demonstrates edge-computing AI, allowing for real-time inference without server-side processing for a fast and interactive user experience.

## 🚀 Tech Stack
* **Machine Learning:** TensorFlow.js
* **Frontend:** HTML5, CSS, Vanilla JavaScript
* **Deployment:** GitHub Pages

## 📁 Architecture
* `index.html` / `validar.html`: Application UI and model inference logic.
* `/tfjs_model`: Contains the model architecture (`model.json`), learned parameters (`weights.bin`), and topological metadata.
